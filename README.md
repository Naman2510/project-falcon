# Project Falcon — Razorpay IB Work Sample

Three linked investment-banking work-sample deliverables built around a single, real, timely situation: **Razorpay's FY2027 IPO** (confidential DRHP filed with SEBI in 2026) evaluated against a dual-track strategic-alternatives process. Sector: Indian & global digital payments infrastructure / FIG.

All figures are drawn from public reporting (company disclosures, press coverage, market-data sites) as of 10 September 2026, cited in each document's Appendix/Sources section. This is an illustrative portfolio piece — not a live mandate, and not published by or on behalf of any bank.

## Contents

| File | What it is |
|---|---|
| [`razorpay-comps-precedents.html`](razorpay-comps-precedents.html) | Trading comparables (Adyen, PayPal, Fiserv, Global Payments, Block, Paytm) with correct TTM calendarization, 6 sourced precedent M&A transactions, Razorpay's own bolt-on M&A history, and a 4-method valuation football field. |
| [`razorpay-pitch-onepager.html`](razorpay-pitch-onepager.html) | A one-page banker-style pitch: situation overview, strategic rationale for a dual-track IPO/strategic-alternatives process, valuation summary, and a numbered process recommendation with a pre-agreed off-ramp. |
| [`razorpay-industry-note.html`](razorpay-industry-note.html) | An 8-section sector deep-dive on India digital payments: market sizing, value chain, regulatory landscape (the August-2026 UPI-MDR law change), competitive landscape, global read-across, and the 2025-26 fintech IPO wave. |

## How to view

Open any `.html` file directly in a browser — each is self-contained (no build step, no dependencies). All three share one visual system (Source Serif 4 / IBM Plex Sans / IBM Plex Mono) and support both light and dark mode.

## Method

Built to demonstrate the "Tier 2: Differentiators" skill set in IB recruiting prep: a real comps set with correct calendarization and defensible multiple selection, a precedent-transactions table pulled from actual announced deals, a banker-style one-page pitch, and sector fluency in written form — all triangulated against the same underlying numbers so the three documents reinforce rather than duplicate each other.
